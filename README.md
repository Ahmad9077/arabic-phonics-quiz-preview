# صدى الحروف

اختبار عربي صوتي للأطفال: يسمع المتعلّم صوت الحرف القصير مع الفتحة، ثم يختار الحرف الصحيح
من أربعة اختيارات. تتوازن كل جولة بين الشكل المنفصل مثل `ع`، والأولي مثل `عـ`، والنهائي
مثل `ـع`.

## ما تتضمنه الجولة

- 15 سؤالًا و15 حرفًا مختلفًا: 5 منفصلة، 5 أولية، و5 نهائية.
- 28 ملف MP3 محليًا بدل الاعتماد على نطق المتصفح.
- أول اختيار يُقفل، مع تغذية راجعة عربية ومراجعة كاملة بعد النهاية.
- مستويات easy وmedium وhard تغيّر مدى تشابه الحروف المشتتة.
- توافق جاهز للدخول، والتكيّف، والتقدم، والتحدي في Quizzes Hub.

## التشغيل المحلي

```sh
npm install
npm run dev -- --host 127.0.0.1
```

نسخة `preview` مستقلة عمدًا: لا تحمّل عملاء Quizzes Hub، ولا تتصل بـSupabase، ولا تسجل
نتيجة أو تعيينًا. نسخة `production-hub` هي النسخة المنشورة التي يتكامل معها الموقع الموحد.

## التحقق

```sh
npm run check
npm run test:e2e
```

تشمل البوابة lint وTypeScript واختبارات 1,000 جولة، وسلامة 78 شكلًا، وفحص 28 ملفًا صوتيًا،
وصحة manifest، وبناء نسخة المعاينة. تشمل اختبارات المتصفح القفل عند أول إجابة، والنتيجة،
ولوحة المفاتيح، وreduced motion، وإتاحة Axe، ومقاسي 320 و390×844، وعزل المعاينة، وعقود
Hub والتحدي المحاكية.

## الصوتيات

الملفات الحالية هي النطق **B** المعتمد، مولّدة بصوت **Layla - Modern Arabic** عبر
ElevenLabs Multilingual v2، مع تثبيت اللغة على العربية، والسرعة الطبيعية `1.0`، والثبات
`0.8`، والتشابه `0.91`، والمبالغة الأسلوبية `0`. يبدأ التصدير بعبارة حاملة ثم نطقين طبيعيين
للحرف. تستخرج أداة المعالجة النطقين بلا تمديد زمني، وتوحّد فقط زمن ما قبل النطق والفاصل
الصامت بينهما، ثم تصدّرهما إلى MP3 أحادي 44.1kHz/128kbps.

لإعادة المعالجة، ضع تصديرات ElevenLabs في مجلد خارجي بأسماء مثل `ain-raw.mp3` ثم شغّل:

```sh
npm run generate:audio -- /path/to/elevenlabs-raw
npm run validate:audio
```

التصديرات الخام لا تُنشر ضمن الموقع؛ الملفات النهائية المحلية هي الوحيدة التي يحملها المتصفح.

## النشر

ينشر المستودع نفسه وضع `preview` في مستودع المعاينة، ووضع `production-hub` في مستودع
الإنتاج `arabic-phonics-quiz`. التكامل مع كتالوج Quizzes Hub وملفات صعوبة الحروف موثق في
[دليل الدمج](integration/production-hub-catalog.md).

[`specs/001-arabic-phonics-quiz/`](specs/001-arabic-phonics-quiz/).
